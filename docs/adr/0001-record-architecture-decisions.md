# ADR-0001: Record architecture decisions

- Status: accepted · Date: 2026-10-18

## Context
Matchcut combines simulation, computer vision, AI agents, video rendering and cloud infrastructure. Decisions in one area constrain the others, so they must be explicit and reviewable.

## Decision
Every significant decision is an ADR in `docs/adr/`, numbered, in this format: context, decision, options considered, consequences. An ADR is never rewritten once accepted. A later ADR supersedes it and links back.

## Consequences
Reviewers and judges can see *why* the system looks the way it does. Changing a decision costs one short document.
