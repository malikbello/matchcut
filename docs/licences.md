# Third-party assets and licences

Every third-party asset Matchcut uses, its licence, and how we comply. Code dependencies are covered by the lockfile and the automated licence check; this register covers data, media and design assets.

| Asset | Source | Licence | How we use it | Compliance |
|---|---|---|---|---|
| Azure architecture icons | Microsoft | Azure icon terms (diagrams and documentation only) | Architecture diagrams | Used unmodified; credited; only the icons a diagram uses are embedded |
| Big Shoulders Display, Inter, JetBrains Mono | Google Fonts | SIL Open Font License 1.1 | UI, broadcast graphics, films | Free to bundle; licence text shipped with fonts |
| Football animations (Soccer Game Pack and selected clips) | Mixamo (Adobe) | Mixamo terms: free and royalty-free in projects; raw files may not be redistributed | Player actions in the 3D show camera | Raw files are **never committed** (`assets-private/` is git-ignored) and are stored privately; they are only shipped baked into the product; the public build falls back to the sources below |
| Locomotion animations | Quaternius Universal Animation Library | CC0 1.0 (public domain) | Running and movement in the 3D show camera | No restrictions; credited anyway |
| Motion capture (soccer actions) | CMU Graphics Lab Motion Capture Database | Free for research and commercial use; the data may not be resold | Real human motion for actions | Used inside the product only; never sold as data; credited |
| Pitch, grass and lighting textures (planned) | Poly Haven | CC0 1.0 | 3D stadium and pitch | No restrictions; credited anyway |
| Demo film narration voice | Deepgram Aura-2 ("Arcas") | Deepgram terms (account holder's licence) | Voice-over in the submission video only | Generated under the account holder's own subscription |

All clubs, players, grounds and matches are fictional and generated by Matchcut. No real match data or footage is used.
